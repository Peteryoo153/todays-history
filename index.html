해설 오류 제보, 개념 카드 수정 요청, 불편 사항은 아래 링크에 남겨 주세요. 확인 후 다음 업데이트에 반영합니다.

문의 남기기 (GitHub Issues)

GitHub 계정이 없다면 App Store의 앱 페이지에서 "앱 지원"을 통해 연락할 수 있습니다.

자주 묻는 질문

기출 문제는 어떻게 푸나요?
앱에서 국사편찬위원회의 공식 문제지(PDF)를 열어 보며 답안지에 번호를 마킹하면, 앱이 채점하고 문항별 해설과 관련 개념을 보여 줍니다. 종이 문제지로 풀고 앱에서 채점만 해도 됩니다.

무료로 쓸 수 있나요?
선사~남북국 개념 회독, 급수마다 가장 최근 기출 1회차, 예시 문항은 언제나 무료입니다. 7일 무료 체험으로 모든 기능을 써볼 수 있고, 체험이 끝나도 자동으로 결제되지 않습니다.

전체 잠금 해제는 구독인가요?
아니요. ₩9,900 일회 결제이며, 같은 Apple ID로 로그인한 아이폰·아이패드에서 함께 쓸 수 있습니다.

구매 내역을 복원하려면?
앱의 설정 > 구매 복원을 누르세요.

기기를 바꾸면 기록이 사라지나요?
iCloud에 로그인되어 있으면 학습 기록이 자동으로 동기화됩니다.

기출 자료와 저작권

한국사능력검정시험 기출 문제지와 정답표의 저작권은 국사편찬위원회에 있습니다(공공누리 제4유형). 이 앱은 문항을 앱에 싣지 않고, 국사편찬위원회 한국사능력검정시험 시험 자료실의 공식 파일을 그대로 열어 보여 줍니다. 해설, 개념 카드, 채점 기능은 이 앱에서 직접 작성했습니다. 이 앱은 국사편찬위원회와 관련이 없습니다.
